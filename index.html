Learning Something New

October 10, 2026 by Malachi Clarke

This week, I am learning a new topic this where I build page layouts with CSS Grid. I made plenty of mistakes along the way, from missing units to selectors that matched nothing, but each one showed me how the browser works with each block.

This matters for web development because nearly every site is a set of boxes arranged on a page. Grid handles the overall structure, Flexbox centres content inside a box, and float wraps text around images. Knowing which tool fits which job is a skill I will keep using, and I am looking forward to building more with it.
